# HARSHU 🌿
### AI-Powered, Voice-First Digital Guide for First-Time Women Internet Users

> **"Just speak. HARSHU will guide you."**  
> *(பேசுங்கள் போதும். HARSHU உங்களுக்கு வழிகாட்டும்.)*

---

## 🌟 Core Product Identity

### The HARSHU Acronym
The name **HARSHU** is an intentional product identity designed for empathy, trust, and human dignity:

* **H** — **Help** *(உதவி / मदद)*
* **A** — **Access** *(அணுகல் / पहुंच)*
* **R** — **Resources** *(வளங்கள் / संसाधन)*
* **S** — **Simply** *(எளிமையாக / सरलता से)*
* **H** — **Her** *(அவள் / उसका)*
* **U** — **Understanding** *(புரிதல் / समझ)*

### Core Philosophy
> **"Technology should adapt to the woman — not force the woman to adapt to technology."**  
> *"You don't need to know technology. Just tell me what you need."*

---

## 🚀 The Core Innovation — "DO IT WITH ME"

Unlike conventional chatbots that dump walls of text or external links saying *"Here is a portal, go apply"*, HARSHU transforms intent into an interactive, step-by-step companion experience:

```
SAY ➔ UNDERSTAND ➔ GUIDE ➔ DO (With Me) ➔ COMPLETE
```

1. **Step-by-step guidance**: Progress is broken down into 4 digestible micro-steps with clear progress tracking (*"இன்னும் 2 படிகள் மட்டுமே"*).
2. **"I Don't Understand" (எனக்கு புரியவில்லை) as a First-Class Feature**: Every single step provides an instant button that translates instructions into ultra-simple vernacular language with tangible daily examples and audio read-aloud.
3. **Emotional Safety from Beginning to End**: Zero shame, zero judgment, and no permanent dead-ends. The user can go back, change answers, or retry anytime.
4. **Privacy-First Design**: Never collects passwords, OTPs, or Aadhaar numbers.

---

## 🪟 Opening Experience — Glyph Portal

The landing experience is built on the **Glyph Portal** scroll-driven typography gateway:
* Massive, centered **HARSHU** typography that dominates the screen with smooth 3D camera zoom.
* Interactive letters that reveal the deeper meaning of each letter on hover or tap.
* Native support for `requestAnimationFrame`, `ResizeObserver`, touch interaction, keyboard navigation, and reduced-motion fallback.

---

## 🌐 Multilingual Support

Built from the ground up for Indian vernacular languages:
* **தமிழ் (Tamil)** — Default
* **हिन्दी (Hindi)**
* **English**

Includes full speech synthesis (TTS) reading aloud instructions warmly in all three languages.

## 🛠️ Tech Stack

* **Framework**: React 18 with TypeScript
* **Build Tool**: Vite
* **Styling**: Tailwind CSS with custom natural forest/earth color system
* **Icons**: Lucide React
* **Speech Integration**: Web Speech API (Recognition + Synthesis) with offline fallback
* **Celebration**: Canvas-Confetti

---

## 🏃 Running Locally

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
